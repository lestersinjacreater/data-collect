# Donor notice (send this with the APK)

**English**
You are donating your received SMS, once, to our hackathon team to train a scam-detection model.
Before the file is created the app hides codes (OTP/PIN), ID numbers, card numbers and phone numbers.
You can leave out any sender. The app has no internet access: you send the file yourself, only to the team.
When you tap "Finish", the file is deleted from your phone. Donating is voluntary; do not install if you prefer not to.

**Kiswahili**
Unachangia jumbe ulizopokea, mara moja, kwa timu yetu ya hackathon ili kufundisha mfumo wa kutambua ulaghai.
Kabla faili kutengenezwa, programu huficha misimbo (OTP/PIN), nambari za kitambulisho, kadi na simu.
Unaweza kuacha nje mtumaji yeyote. Programu haina intaneti: unatuma faili mwenyewe, kwa timu pekee.
Ukibonyeza "Maliza", faili inafutwa kwenye simu yako. Kuchangia ni hiari; usisakinishe ukipendelea hivyo.
